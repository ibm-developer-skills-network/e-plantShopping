Paradise Nursery Shopping Application
A responsive React-based front-end application designed for a houseplant nursery. This project allows users to browse a curated collection of plants, manage a dynamic shopping cart, and calculate costs in real-time.

🌿 Project Features
1. Landing Page
Immersive Experience: Features a high-quality background image and a compelling brand story.

Call to Action: A "Get Started" button that directs users straight to the product gallery.

2. Product Listing
Organized Catalog: Plants are categorized into at least three distinct groups (e.g., Air Purifying, Low Maintenance, etc.).

Dynamic UI: Each product card includes a thumbnail, pricing, and an "Add to Cart" button.

Live Header: A persistent navigation header with a dynamic cart icon tracking the total item count.

3. Shopping Cart Management
Full CRUD Functionality: Users can increase, decrease, or delete specific plant types from their cart.

Real-Time Calculations: Updates total item counts and the final cost instantly upon adjustment.

Navigation: Integrated "Continue Shopping" and "Checkout" (placeholder) functionality.

🛠️ Technical Implementation
Framework: Built with React.js.

State Management: Handles dynamic cart updates and navigation across three primary views.

Deployment: Hosted via GitHub Pages.

🚀 Getting Started
Clone the repository.

Run npm install to install dependencies.

Run npm start to view the application in development mode.

Open http://localhost:3000 to view it in your browser.
