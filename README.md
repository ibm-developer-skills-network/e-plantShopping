# coding-project-template
Name : e-plantShopping

Project Learning react 

e-plantShopping is a React-based frontend application designed to simulate an online nursery shopping experience. The project showcases essential React concepts such as component-based architecture, state management, event handling, and dynamic rendering of UI elements. It serves as a practical learning project for building interactive user interfaces using modern frontend development practices.


Project Overview
The e-plantShopping application allows users to:

Browse a selection of plants

View plant details

Add items to a shopping cart

Manage cart contents using Redux Toolkit

This project was developed as part of a learning module for building responsive and interactive React applications, preparing learners for more advanced frontend development tasks.
