# coding-project-template

Application Title: e-plantShopping App

Overview 

This project covers an e-commerce website that will consist of Three pages, 1.-A Landing Page, 2.-A Plant page & 3.-A Checkout page.
The landing page provides a brief description of what the business is about and what is provided within the service. The plant page
provides a catalogue of plants to purchace alongside there corresponding images. Checkout will list the total and quantity of items
selected with the Total Price of the full order.
