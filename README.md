# e-plantShopping

e-plantShopping is a React-based web application for browsing and shopping for plants online. It provides a simple, user-friendly interface where users can explore plant products and manage their shopping experience.

## Features

- Browse a collection of plants
- View plant names, prices, and images
- Add plants to a shopping cart
- Responsive and easy-to-use interface

## Technologies Used

- React
- JavaScript
- HTML
- CSS
