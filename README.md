🌱 e-plantShopping
e-plantShopping is a React-based frontend application that simulates an online nursery shopping experience. It demonstrates core React concepts such as component-based architecture, state management, event handling, and dynamic UI rendering. The project serves as a practical exercise for building interactive and responsive user interfaces using modern frontend development practices.

🌿 Project Overview
The e-plantShopping application enables users to:

Browse a curated list of plants

View detailed information for each item

Add plants to a shopping cart

Manage cart contents using Redux Toolkit

Navigate seamlessly between the plant listing and cart pages

This project is part of a learning module designed to strengthen your React fundamentals and prepare you for more advanced frontend development tasks.
