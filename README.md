# e-plantShopping

## Overview
**e-plantShopping** is an interactive web application designed to provide a seamless online shopping experience for plant enthusiasts. Users can browse a wide selection of houseplants, learn about care requirements, and easily add items to their shopping cart for purchase.

## Key Features
* **Product Catalog:** View various indoor and outdoor plants with detailed descriptions and pricing.
* **Shopping Cart:** Add, update quantities, or remove plants from your cart dynamically.
* **Responsive Design:** Optimized for both desktop and mobile viewing.

## Tech Stack
* **Frontend:** React, HTML5, CSS3, JavaScript
* **Build Tool:** Vite

## Getting Started

### Prerequisites
* Node.js (v14 or higher)
* npm

### Installation
1. Clone the repository:
   ```bash
   git clone [https://github.com/hoangminhq5310/e-plantShopping.git](https://github.com/hoangminhq5310/e-plantShopping.git)
2. Navigate into the project directory:

  Bash
  cd e-plantShopping
  
3. Install dependencies:

  Bash
  npm install
  
4. Start the development server:

  Bash
  npm run dev
