# 🌱 e-PlantShopping

**A sleek, interactive React-based e-commerce app for plant lovers.**

---

## 🔹 Overview
e-PlantShopping lets users explore, select, and purchase plants online with a modern, responsive interface. It provides a smooth shopping experience from browsing to checkout.

---

## 🔹 Key Features
- **Dynamic Product Catalog:** Browse plants by category with detailed info.  
- **Interactive Shopping Cart:** Add, remove, and update items seamlessly.  
- **Responsive Design:** Works beautifully on desktop and mobile.  
- **State Management with React Hooks:** Efficiently handles user interactions.  
- **Extras:** Filtering, sorting, and a simple checkout workflow.

---

## 🔹 Tech Stack
- **Frontend:** React, JavaScript, HTML, CSS  
- **State Management:** React Hooks (useState, useEffect)  
- **Optional Enhancements:** Context API for global state

---

## 🔹 Purpose
This project showcases practical React skills, including **component-based architecture, state management**, and building a **responsive, user-friendly UI** for a real-world e-commerce application.
