# coding-project-template
- This is the repo for e-plantShopping.
- I'll be utilizing React components with different hooks and states. 
- Also will be using Redux and Redux ToolKit to implement the solution. 
- The application starts you off with a landing page with a description and a "Get Started" button that directs you to the catalog of plants.
- Here you can browse different kinds of plants. Each have a card with image, description, cost and a "add" button.
- Nav bar that has 3 sections. First one directs you to landing page. Second one is the plants. Third one is the shopping cart.
- Shopping cart, you'll be able to view the plants added, along with two other buttons to either "continue shopping", or "checkout".
